# Compatibility

The adapter accepts stable Terraform **1.5–1.17** and OpenTofu **1.6–1.13**, using the documented common `show -json` interface and JSON state format major version 1. Prereleases, other engine major versions, plan JSON, duplicates, and malformed records fail closed. Tests use synthetic official-format output and fake executables. Terraform 1.5.5, 1.5.7 and 1.17.2 and OpenTofu 1.6.3 and 1.13.9 have also been run for real against disposable projects (local backend; built-in resources and the `random` and `local` providers from a local mirror), with the platforms and exceptions listed per row; no cloud provider or remote backend has been certified. The [support matrix](../support-matrix.md) lists what has and has not been run for real. Remote/cloud backends are read-only, with execution mode shown explicitly. An initialized project with no `backend` or `cloud` block uses the default local backend; otherwise absent metadata remains unknown.

See also [config-compatibility.md](../config-compatibility.md) for the configuration files Hclaro writes, [plan-actions.md](../plan-actions.md) for plan action semantics and [Status, testing and limitations](limitations.md).
