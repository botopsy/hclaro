## Historical mockup assessment

Reviewed privately from the backup bundle in a temporary location that was deleted afterwards; no content is reproduced here.

- **Origin.** The owner states it was generated by ChatGPT specifically for hclaro. Its accompanying README calls it "a design mockup created in a visual design tool"; both are consistent with an AI-produced design export. This review cannot independently verify provenance.
- **Content.** A single 5.3 KB HTML artboard showing the hclaro wordmark and `h` app mark in the brand colours: inline styles, the word "hclaro", one SVG chevron, and a five-line component class in the design tool's export format. Every value it carries is already documented in `docs/design/BRAND.md`.
- **Third-party material.** No copyright, license or author notices; no embedded images, fonts or data URIs; no copied code bodies. It *references* (does not contain) a React runtime and design-tool support script that were never committed, and a Google Fonts URL for JetBrains Mono (OFL-1.1, the font hclaro already bundles with its notice).
- **Secrets.** Gitleaks v8.21.2 on the extracted files: no leaks.
- **Distribution.** Not part of the application, the embedded UI or any release archive; absent from every local branch and tag, and absent from the three remote branches after synchronization.
- **Uncertainty.** AI-generated output is not guaranteed to be original, and no tool can prove the absence of similarity to existing work. Nothing specific was found: the artboard depicts hclaro's own name and simple geometric shapes.

**Classification:** accepted, documented historical risk. After synchronization the file stays readable through the closed pull requests #36 and #37 (their *Files changed* views and the original commit IDs) and possibly through cached views. This is not a publication blocker.

## Synchronization commands (executed)

Run from `hclaro-codex-handoff` on this machine.

```sh
# 1. Remote must still be exactly as verified; abort if any line differs.
git ls-remote origin refs/heads/master refs/heads/m19-brand-identity refs/heads/m21-navigation-ia
#   8c8de781cf6c8f1987a905b0e760005120ffd9a2  refs/heads/master
#   bf55d7f03e27f348fdc452d7bdd1a98670bf15b3  refs/heads/m19-brand-identity
#   83cfd6e8f9a3bb7c5b268b068e2beddcac11c0c6  refs/heads/m21-navigation-ia

# 2. Update the three branches together (all or nothing), each pinned to the verified remote commit.
git push --atomic origin \
  --force-with-lease=refs/heads/master:8c8de781cf6c8f1987a905b0e760005120ffd9a2 \
  --force-with-lease=refs/heads/m19-brand-identity:bf55d7f03e27f348fdc452d7bdd1a98670bf15b3 \
  --force-with-lease=refs/heads/m21-navigation-ia:83cfd6e8f9a3bb7c5b268b068e2beddcac11c0c6 \
  35c77ee7ce1c0397701ee0c7342b7b81fa54308a:refs/heads/master \
  e7d02f69d41a085518d853765635711d212a8ea6:refs/heads/m19-brand-identity \
  390ec5fc3292d5afbedb6f528e505fca69817356:refs/heads/m21-navigation-ia

# 3. Verify, then update the local view of GitHub.
git ls-remote origin refs/heads/master refs/heads/m19-brand-identity refs/heads/m21-navigation-ia
git fetch --prune origin
git for-each-ref --contains 4f920f6 --format='%(refname)'   # expect no output except reflogs/backup
```

The same command with `--dry-run --porcelain` was run on 2026-11-09: three forced updates (`8c8de78…35c77ee`, `bf55d7f…e7d02f6`, `83cfd6e…390ec5f`), leases accepted, exit 0, nothing written.

Not used: unconditional `--force`, `--mirror`, tag pushes, branch deletion. Explicit commit IDs as sources mean a local branch that moved in the meantime cannot be pushed by mistake.
